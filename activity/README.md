# 经理排行榜接入

本目录是活动 `app_2eeb0a1013` 的经理排行榜后端。游戏内入口位于“生涯总览”，榜单页面是 `public/leaderboard/index.html`，构建后为 `h5/leaderboard/index.html`。玩家从游戏进入榜单时自动同步当前成绩；仅在同步失败时显示重试按钮。`public/leaderboard/config.js` 已填写经过真实接口验证的活动网关与环境，更新后运行 `npm run build`。

生涯总览会读取登录账号的名次并同步存档成绩与资料。榜单详情展示个人名次、当前存档的球队/赛季/称号，以及前 100 名的虎扑昵称、头像、球队和赛季。积分表示账号的历史最高分；球队、赛季与用户资料表示最近提交的当前存档，同分或低分也会更新这些资料。老账号未提交新资料前头像、球队、赛季为空，由页面显示已有的占位内容；服务未配置或不可用时明确显示不可用状态，不生成虚构名次。

## 路由

| 路径 | 网关鉴权 | 用途 |
| --- | --- | --- |
| `GET /api/health` | 否 | 健康检查 |
| `GET /api/leaderboard` | 否 | 公开榜单，默认 50 条，最多 100 条 |
| `GET /api/leaderboard/me` | 是 | 当前登录用户的名次 |
| `POST /api/leaderboard/submit` | 是 | 提交成绩证明；用户身份只来自网关注入的上下文 |

所有浏览器调用经 `window.ColorboxAI.cloud.request`。受保护路由须配置网关鉴权，跨域路由须启用安全域名校验。函数部署在目标活动唯一的 `activity_api`。迁移在确认 `demo_items` 为空后改名，并清理平台自动重建的空演示表与演示路由。

排序为 `score DESC, updated_at ASC, id ASC`；仅在积分提高时更新达到时间。写入有一分钟冷却，同分或低分提交不降低最高成绩。服务端按赛季与成就证明复算积分，并校验部分成就门槛及赛季记录范围。游戏当前在本地运行，整份客户端存档仍可被伪造；要获得抗伪造保证，比赛事件须由可信服务端记录或重演。

资料提交格式为 `{ proof, displayName, avatarUrl }`，`proof` 包含 `teamName`、`teamLogo`、`seasonId` 和显示用 `title`。服务端根据已校验的证明推导称号，并结合账号最高积分的 1500/4000/7500 档位返回称号，不直接信任客户端称号。榜单、个人名次、提交成功统一返回 `id, rank, score, displayName, avatarUrl, teamName, teamLogo, seasonId, title`，不返回 `puid`。提交成功已包含个人名次，客户端无须再请求 `/leaderboard/me`。
