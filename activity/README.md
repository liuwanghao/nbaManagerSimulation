# 经理排行榜接入

本目录准备了对现有活动 `activity_api` / `demo_items` 的改造。游戏内入口位于“生涯总览”，榜单页面是 `public/leaderboard/index.html`，构建后为 `h5/leaderboard/index.html`。玩家从游戏进入榜单时自动同步当前成绩；仅在同步失败时显示重试按钮。发布前须将 `public/leaderboard/config.js` 中的两个空值替换为**目标活动**实际的网关 `/api` 地址和环境 ID，并重新运行 `npm run build`。

生涯总览会读取登录账号的名次，并在本地积分高于账号最高分时自动提交。榜单详情展示个人名次、当前存档的球队/赛季/荣誉，以及前三名和前 100 名的昵称、积分。公开接口没有其他玩家的球队、头像或冠军数据，列表不推测这些信息；服务未配置或不可用时明确显示不可用状态，不生成虚构名次。

## 路由

| 路径 | 网关鉴权 | 用途 |
| --- | --- | --- |
| `GET /api/health` | 否 | 健康检查 |
| `GET /api/leaderboard` | 否 | 公开榜单，默认 50 条，最多 100 条 |
| `GET /api/leaderboard/me` | 是 | 当前登录用户的名次 |
| `POST /api/leaderboard/submit` | 是 | 提交成绩证明；用户身份只来自网关注入的上下文 |

所有浏览器调用经 `window.ColorboxAI.cloud.request`。受保护路由须配置网关鉴权，跨域路由须启用安全域名校验。函数只部署到目标活动**已有的** `activity_api`。迁移会在确认 `demo_items` 为空后改名，不会清空已有记录。

排序为 `score DESC, updated_at ASC, id ASC`；仅在积分提高时更新达到时间。写入有一分钟冷却，同分或低分提交不降低最高成绩。服务端按赛季与成就证明复算积分，并校验部分成就门槛及赛季记录范围。游戏当前在本地运行，整份客户端存档仍可被伪造；要获得抗伪造保证，比赛事件须由可信服务端记录或重演。

当前仓库只包含目标活动 ID，未提供对应云环境凭据或网关地址。因此尚未执行迁移、函数更新、路由配置和登录态读写冒烟，也未填写活动 manifest。取得正确活动环境并确认发布后，先只读检查现有 `demo_items`、函数、网关及权限，再应用迁移和函数更新；用 `curl` 验证公开读取、未登录写入 401、登录写入成功及同分排序。不要使用本技能包内绑定到其他活动的部署脚本。
