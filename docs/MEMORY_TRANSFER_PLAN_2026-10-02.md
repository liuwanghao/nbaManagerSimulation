# 减少生涯状态跨线程复制的执行计划

目标：在上一轮优化基础上减少每次连续模拟的完整输入副本，以及存档的整份 JSON 在线程间往返。保持存档格式、旧档兼容、固定 Seed、保存成功才更新页面与资源失败禁止误判损坏。

1. 保留当前源码与生产构建为对照；先锁定模拟输入/回退及存档恢复、压缩、迁移行为。
2. 模拟 Worker 保留最近一次成功结果。主线程通过 WeakMap 为返回的状态登记 Worker 身份和版本；仅当下一次输入就是该对象且版本匹配时发送操作。经理编辑、读档、保存失败后旧状态重试、线程重启、并发失配均完整重同步。后台任务失败清缓存；回退仍使用主线程原始输入。结果暂时完整返回，以保留现有 UI 的数据接口。
3. 增加可选的存储原始编码接口，在现有 IndexedDB / localStorage 及迁移适配器中使用。存档 Worker 一次完成哈希、JSON 与 gzip；主线程只持有小的存档头和已编码内容。暂存、校验、备份、主档复用编码内容；没有此能力的自定义/云适配器保留原路径。严格保留迁移原子插入、校验后删除旧副本、quota 恢复和副本恢复规则。
4. 新增有意义的回归：连续状态复用、经理/读档/未提交结果失效、并发版本失配重同步、Worker 错误/重启回退、原输入保持不变；编码写入/读回异常不提交、格式一致、迁移竞争、坏档与资源失败。
5. 使用固定五赛季存档，按原有 130 次导航、20 场比赛、5 次保存流程做 production before/after；核对最终 stateHash、revision、日历和记录，重复测量峰值与静置内存。无实际收益的方案不保留。
6. 跑全量测试、TypeScript、生产构建、静态差异检查和独立审查。保留既有并行改动，不引入依赖、不部署或修改发布 ZIP。

职责：模拟子任务只修改 simulationWorkerClient / simulation.worker / 共享协议与对应测试；存档子任务只修改 SaveService / SaveCodec / SaveEnvelopeCodec / StorageAdapter 与对应测试。主代理负责集成、构建与实测。跨职责接口变更由主代理协调。

更大改造：页面只接收视图和增量、经理操作统一由后台执行、历史分层持久化，需要另行建立统一提交/回滚边界。本轮不以删掉历史或跳过完整性检查换取内存下降。
