# 《篮球经理：扩军时代》V1.5 UI 原型需求

## 1. 原型目标

本文档只整理当前已实现或已有游戏数据支持的功能，供设计师制作移动端 H5 UI 原型。不新增战术布置、实时比赛操作、多人联机等 V1.5 之外的玩法。

- 主平台：虎扑 App 内的竖屏移动 H5。
- 基准画板：390 × 844，同时兼容 360px 小屏和平板/桌面预览。
- 关键操作页应遵守顶部/底部安全区，主 CTA 尽量固定在容易点击的位置。
- 球员不使用头像，以姓名、位置、数字属性和球队识别色表达。
- 30 支现实球队使用虎扑授权 Logo；2 支扩军球队使用每城 4 套预设 Logo。

## 2. 整体信息架构

建议将当前的长页面重组为三层：

1. **强流程全屏页**：扩军开局、选秀、自由市场、名单锁定等必须顺序完成的阶段。
2. **赛季常驻导航**：首页、阵容、管理、联盟、生涯 5 个主页。
3. **全局弹层/状态层**：球员详情、比赛详情、随机事件、重大伤病、紧急名单和存档冲突。

赛季常驻底部导航建议：

| Tab | 主要用途 |
|---|---|
| 首页 | 赛季状态、下一场比赛、模拟推进、最近结果与警报 |
| 阵容 | 球员名单、能力/合同/数据/健康、球队 Fit |
| 管理 | 交易、工资帽、合同、选秀权资产 |
| 联盟 | 东西部排名、联盟领袖、MVP 竞争、32 队、联盟新闻 |
| 生涯 | 赛季历史、奖项、名人堂、GM 等级、王朝分与成就 |

## 3. 设计交付页面清单

建议至少输出 **18 个主画板 + 6 类弹层/特殊状态**。同一模板内的加载、空、错误、禁用状态可做成 Variant。

### 3.1 系统启动（1 个主画板）

#### SYS-01 真实数据同步

**显示**

- 标题“正在同步真实球员名单”。
- 30 支球队进度：`x / 30`、进度条。
- 数据范围：当前阵容、位置、赛季数据、年龄和多年薪资。
- 数据源标识：虎扑实时阵容。

**Variant**

- 加载中。
- 同步成功。
- SDK 不可用/网络失败：错误原因 + “重新同步”按钮。
- 本地 Fixture 预览须明确标注“虚构测试名单”。

### 3.2 扩军开局（6 个主画板）

#### EX-01 创建扩军球队

**显示**

- 流程进度与阶段名。
- 城市选择：Seattle / Las Vegas。
- 球队名输入与命名规则提示。
- 当前城市 4 套预审核 Logo：Logo、球队名、简称。
- 主色、辅色选择及实时品牌预览。
- 主 CTA：“确认球队并进行权益抽签”。

**必须状态**

- 默认/选中 Logo。
- 球队名合法与非法。
- 提交处理中。

#### EX-02 扩军权益抽签

**显示**

- 50/50 抽签结果与获得优先权的球队。
- Package A：扩军选秀 #1、新秀首轮 #6、次轮 #38。
- Package B：扩军选秀 #2、新秀首轮 #5、次轮 #37。
- 选择不可普通撤销的提示。
- 若 AI 获得优先权，显示 AI 策略及最终分配。
- 两支扩军队最终 Package 结果。

#### EX-03 扩军前合同选项结算

**显示**

- 已执行选项人数、已拒绝选项人数、被排除的 UFA/RFA 人数。
- 规则：只有下赛季仍有有效合同的球员能进入保护名单/扩军池。
- 引擎结算通知。
- 主 CTA：冻结保护名单并查看报价。

#### EX-04 扩军交易桌

**顶部指标**

- 30 支现有球队。
- 每队保护 8 人。
- 已接受协议 `x / 5`。

**报价卡片**

- 类型：指定选择/保护球员。
- 来源球队 Logo 与队名。
- 球员姓名、主/副位置、年龄、年薪、剩余年限。
- 补偿选秀权年份与轮次。
- “详情”、“接受”，允许全部跳过。
- 已接受/已履行/已失效 Variant。

#### EX-05 扩军选秀室

**显示**

- 当前总签位、轮次、当前选择球队。
- 本队阵容人数 `x / 14`。
- 可选球员列表：原球队 Logo/简称、姓名、主/副位置、年龄、合同。
- “球员详情”与“选择”。
- 扩军交易指定选人时，显示协议锁定标识。
- AI 选择中、轮到玩家、选择成功三种状态。

#### EX-06 扩军完成总结

**显示**

- 两支扩军队的 Logo、全称、阵容人数、选人次数。
- 可展开的完整名单：姓名 + 位置。
- 已结算的补偿资产说明。
- “恢复扩军选秀前 Checkpoint”。
- 进入新秀选秀的下一步指引。

### 3.3 年度休赛期（6 个主画板）

#### OS-01 年度滚动与球队选项

**显示**

- 当前赛季和“合同选项”阶段。
- 本年成长人数、衰退人数、重点培养生效人数、退役人数、联盟平均 OVR 变化。
- 待处理球队选项列表：姓名、位置、薪资、剩余年限。
- 每人“执行”/“放弃”。
- 合同动态日志和完成阶段 CTA。

#### OS-02 新秀选秀导览

**显示**

- 年份和当届选秀类型。
- 80 名新秀、64 个签位、两轮规则。
- 首届选秀显示玩家的两个确定签位；后续年份显示 16 队乐透与前 4 顺位。
- 只公开 Scouted Potential 和侦察置信度，不显示 True Potential。
- “生成选秀班并进入 Draft Room”。

#### OS-03 新秀选秀室

**显示**

- 当前总签位和拥有球队。
- 本队签位列表与已用/总数。
- Big Board：排名、姓名、主/副位置、年龄、即战 OVR、侦察潜力等级、置信度。
- 选择按钮；AI Picks 结算中的禁用/加载状态。

#### OS-04 选秀结果与 Cap 摘要

**显示**

- 64 签完成状态和 16 名落选秀进入 UFA 的说明。
- 本队每个签位的新秀：签位、姓名、位置、侦察潜力、新秀合同薪资。
- 工资帽、当前 Cap Sheet、可用空间、休赛期名单 `x / 21`。
- 进入自由市场。

#### OS-05 自由市场

**顶部指标**

- Free Agency Day、可签球员数、本队有效报价数、可用薪资空间。
- “结算今日”、固定 3 日决策窗口说明。

**球员列表**

- UFA/RFA 标识、姓名、主/副位置、年龄、OVR、起始要价。
- 市场窗口：等待首份报价/截止 Day。
- “报价”或“撤回”，薪资空间不足时禁用。
- 已受理报价可显示年限、首年薪资、保障比例、承诺角色和效用值。
- RFA Offer Sheet 待处理时强提示：球员、截止日、MATCH/DECLINE。
- 联盟签约动态日志。
- 休赛期交易中心入口和“结束自由市场”。

#### OS-06 季前名单锁定与训练

**显示**

- 开季名单 `x / 15`，合法区间 14～15 人。
- 重点培养 `x / 2`。
- 球员姓名、位置、年薪和剩余年限。
- 训练方向：不指定/综合/投射/组织/防守/内线/运动能力。
- 裁员按钮，剩余 14 人时禁用。
- 超过 15 人时主 CTA 禁用；合法时“锁定名单并进入常规赛”。

### 3.4 赛季常驻页（5 个主画板）

#### SE-01 赛季首页

**首屏信息**

- 球队 Logo、城市、球队名、球队主色。
- 赛季、当前阶段（交易截止日前/后、常规赛、Play-In、Playoffs、休赛期）。
- 胜负记录、常规赛 `x / 82` 进度。
- 当前系统状态：空闲/模拟中/已自动保存/需要决策。

**决策区**

- 下一场日期、主客场、双方 Logo 与队名。
- 上一场比分。
- 模拟下一比赛日、模拟本队 5 场、模拟到下一事件、模拟至季后赛。
- 常规赛结束后：结算 Play-In 与季后赛。
- 休赛期：进入下一联盟年度。

**赛季动态**

- 最近 5 场：W/L、对手、主客、比分，点击进入比赛详情。
- 模拟摘要：场次、胜负、排名变化、主要球员数据、新增伤病、待处理事件。
- 非强制随机事件卡可内联显示。
- 重大伤病、紧急名单、强制事件必须拦截模拟。

#### SE-02 阵容与球队 Fit

**球队指标**

- 总 Fit 分与等级。
- 市场评级、球队声望、球迷支持、自由球员吸引力。
- Fit 分项：组织、空间、侧翼防守、护框、篮板、位置尺寸、替补深度、球权兼容。
- 派生值：OFF、DEF、STAR、HEALTH、比赛修正。

**阵容列表**

- 姓名、主/副位置、年龄、轮换角色。
- OVR、侦察 POT 等级。
- 年薪、剩余年限、合同状态。
- 赛季场均得分/篮板/助攻。
- 健康、士气、伤病等级和剩余缺阵场次。
- 点击球员打开详情弹层。

#### SE-03 管理中心

**常规交易**

- 从本队名单中选择球员获取 3 个动态报价。
- 每份报价显示对方球队、本队送出、对方送入、选秀权、薪资和 Fit 变化。
- 接受交易；重新刷新时要表达“刷新惩罚/询价次数”。
- 交易截止日后整个模块禁用，给出明确原因。

**工资帽/合同**

- Salary Cap、Tax、First Apron、Second Apron、当前薪资、薪资空间/超帽。
- 球员多年薪资、选项年、UFA/RFA、Cap Hold、Dead Money、报价预留和 Emergency Salary。
- 本队持有选秀权：年份、轮次、原属球队。

> 工资帽和选秀权在游戏状态中已存在，现有界面只显示了部分摘要。设计原型可以将其完整可视化，不改变游戏规则。

#### SE-04 联盟中心

**排名**

- 东/西部切换。
- 排名、Logo、球队、胜负、得失分差；高亮玩家球队。
- 默认显示前 10，可展开全部 16 队。

**联盟动态**

- 得分王、篮板王、助攻王：姓名与场均值。
- MVP 竞争前 5：姓名、球队、OVR、PPG。
- 32 队列表：Logo、全称、分区、战绩。
- 联盟新闻/交易/签约/事件日志。
- 玩家球队 82 场完整日历：场次、日期、主客、对手、未赛或比分。

**季后赛 Variant**

- Play-In / Playoffs 阶段标识。
- 季后赛结算结果、本队战绩、系列赛胜场和最终冠军。
- V1.5 引擎是一键结算，原型不应表现为玩家可逐场战术操作。

#### SE-05 生涯与历史

**赛季荣誉**

- MVP、DPOY、ROY、MIP、最佳第六人、Finals MVP。
- 东/西部 All-Star 人数或名单入口。
- 历届冠军。

**名人堂**

- 姓名、入选届次、HOF 得分、巅峰 OVR。
- 现实球员若没有开档前完整历史数据，不参与自动名人堂评选，界面不得伪造历史荣誉。

**GM 生涯**

- 等级：新手经理/优秀经理/联盟精英/冠军经理/王朝经理/传奇经理。
- 王朝分、赛季数、常规赛胜负、季后赛胜负、分区冠军、总冠军。
- 选秀历史、交易历史、最佳选秀球员和最佳交易可作为可展开内容。

**14 项成就**

- 新球队诞生、队史首胜、初具竞争力、第一次附加赛、季后赛初体验、系列赛突破、分区决赛、总决赛、首冠、50 胜、60 胜、自家球星、最佳新秀、王朝雏形。
- 每项显示已解锁/未解锁、解锁赛季和王朝分奖励。

## 4. 全局弹层与特殊状态（6 类）

### OV-01 球员详情

**现实数据**

- 姓名、球队、主/副位置、年龄、身高、体重、国籍。
- 年薪、剩余年限、保障金额、合同状态和选项。

**游戏推演数据**

- OVR、侦察 POT、轮换角色、球队角色。
- 健康、士气、疲劳、状态值、伤病。
- 8 项能力：投射、终结、组织、外防、内防、篮板、运动、球商。
- Traits、性格、耐伤和市场偏好。
- 本赛季、季后赛、生涯场次及 PTS/REB/AST。
- 可修改球队角色；交易截止日前可“加入交易并获取报价”。
- 底部必须标注哪些数据来自虎扑，哪些是游戏推演值。

### OV-02 比赛详情

- 日期、主客队 Logo/简称、总比分、加时标识。
- Q1～Q4 及 OT 分节比分。
- 本场最佳：姓名、PTS/REB/AST。
- 双方 Box Score：球员、MIN、PTS、REB、AST；原型可扩展为完整投篮、抢断、盖帽、失误数据。
- 当场伤病事件若存在应显示。

### OV-03 随机事件

- 类别、优先级、标题、描述、选项。
- 冠军/扩军完成等特殊事件使用专属插画。
- 非强制事件可作为页内卡片；强制暂停事件使用全局弹层。
- 选择后可显示对球员士气/状态、球队球迷支持/声望的影响。

### OV-04 伤病与紧急名单

- 重大伤病：球员、严重度、预计缺阵场次、轮换自动调整说明、“确认并继续”。
- 紧急名单：当前可用人数、最低 8 人规则、临时合同说明、“补齐至 8 人”。
- 两者都会禁止继续模拟，必须有明确拦截态。

### OV-05 存档与云同步

- Slot 1/2/3 切换、保存、读取。
- 本机/云端同步状态、Revision、更新时间、赛季战绩摘要。
- 冲突时对比本机与云端：Revision、赛季、战绩、时间、Hash 摘要。
- 选择“使用本机版本”或“使用云端版本”；使用云端前会生成本机冲突备份。

### OV-06 全局操作状态

- 处理中、提交成功、自动保存成功、云同步成功、只保存到本机、错误但状态未改变。
- 按钮加载、整块禁用、可重试错误、不可撤销操作确认。
- 所有重要操作必须给出明确的成功/失败反馈，不能只依靠按钮消失判断。

## 5. 通用组件清单

设计稿应给出以下可复用组件及 Variant：

- 球队 Logo/徽章：大、小、图片加载失败字母回退。
- 球员行：普通、选中、伤病、不可用、自由球员、新秀。
- 数据指标卡：数值、单位、趋势/变化、风险色。
- 阶段标签、UFA/RFA/球队选项/球员选项/伤病/角色标签。
- 进度条：同步进度、赛季进度、选秀进度、阵容人数。
- 主/次/文本/危险按钮：默认、按下、禁用、加载。
- 列表筛选与分段切换：东/西部、主页 Tab、合同/数据切换。
- 可折叠区：Fit 分项、完整日历、32 队、新闻、合同动态。
- 状态条/Toast：保存、同步、处理、成功、失败。
- 全局弹层、底部抽屉、警报条、插画事件卡。

## 6. 数据表达规则

### 6.1 数据来源必须可辨识

| 数据 | 显示方式 |
|---|---|
| 姓名、当前球队、位置、当前赛季数据、薪资 | 标注“虎扑当前阵容” |
| 身高、体重、生日、国籍 | 球员详情打开时按需同步 |
| OVR、能力、潜力、性格、耐伤、市场偏好 | 标注“游戏推演值”，不得包装成虎扑官方评分 |
| 未来新秀 | 标注“程序生成 Draft Class” |
| 现实球员开档前历史荣誉 | 当前无完整数据，不展示虚构内容 |

### 6.2 金额和状态

- 大额薪资默认用 `$12.5M`，多年薪资表可用万/亿作中文辅助，但同一页口径统一。
- 空间为负、超过 Tax/Apron、名单不合法时，除颜色外还必须有文字/图标。
- 禁用按钮必须同时说明原因，例如“超过工资帽”、“需先处理 RFA”、“交易截止日已过”。

## 7. 原型交互链路

原型至少应打通以下链路：

1. 创建球队 → 权益抽签 → 扩军交易 → 扩军选秀 → 完成。
2. 新秀选秀导览 → Draft Room 选人 → 选秀结果 → 自由市场 → 名单锁定。
3. 赛季首页 → 模拟 5 场 → 结果摘要 → 最近比赛 → Box Score。
4. 阵容 → 球员详情 → 设置球队角色 → 加入交易 → 报价 → Fit 变化 → 接受。
5. 自由市场报价 → 薪资预留 → 结算 Day → 签约/拒绝或 RFA MATCH/DECLINE。
6. 模拟中触发重大伤病/强制事件 → 操作被拦截 → 确认决策 → 继续模拟。
7. 保存 → 云端冲突 → 比较版本 → 选择本机/云端 → 备份与完成提示。

## 8. 响应式与可用性要求

- 关键按钮触摸高度建议不低于 44px。
- 列表要能承受长中英文球员名、球队名和大额薪资。
- 表格在手机上优先改成卡片/分组列表，不应依赖小字号横向硬塞。
- 弹层最大高度不超过安全区，长 Box Score 与球员详情在弹层内独立滚动。
- 颜色不能是 W/L、健康/伤病、已解锁/未解锁的唯一区分方式。
- 移动端支持返回关闭弹层；弹层打开时背景不应继续滚动。
- 所有强流程页显示当前阶段和下一步，避免玩家不知道为何无法返回常规首页。

## 9. V1.5 不需要设计的页面

- 登录/注册页（使用虎扑容器运行时）。
- 球员头像库或头像上传。
- 实时 2D/3D 比赛画面、按键操作球员或单回合战术指挥。
- 球员手工修改器、数值作弊或管理员调参页。
- 多人联机、聊天、排行榜、商城、广告奖励页。
- 球员个人新闻流、球队资讯流等未接入游戏循环的内容页。

## 10. 设计优先级

1. **P0**：EX-01～EX-06、OS-02～OS-06、SE-01～SE-04、OV-01～OV-04。
2. **P1**：SYS-01、OS-01、SE-05、OV-05、季后赛 Variant。
3. **P2**：完整工资帽明细、选秀权资产细表、GM 选秀/交易历史展开页。这些数据已有，但现有界面只提供摘要。
