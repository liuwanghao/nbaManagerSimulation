# NBA 2K27 全能力对齐报告

## 数据口径

- 官方校验源：`https://nba.2k.com/2k27/top-100-ratings/`，仅用于核对官方公开的 Top 100 OVR。
- 完整分项源：NBA2K API 的 NBA 2K27 版本化 bulk 接口，上游数据来自 2K Ratings；当前快照版本为 `nba2kapi-2k27-2026-09-16`。
- 完整分项源不是 2K 官方接口，也不与 2K 存在授权或背书关系；产品文案只能写“参考 NBA 2K27 能力体系”。
- H5 运行时只读取项目内的版本化 JSON，不联网抓取任何评分网站。

## 对齐结果

- API 快照：650 名现役/自由球员，全部包含有效 OVR 与 35 项分项数据。
- 当前项目：NBA 官方名单中已有数据行的 561 人里，558 人使用完整 2K27 档案，覆盖率 99.5%；全数据集共对齐 627 人。
- 联盟 650 人平均 OVR 为 75.07；90+ 球员 21 人，处于冻结文档建议的 5～25 人范围内。
- 官方 Top 100 全部匹配，OVR 平均绝对误差为 0。
- API 球队归属与 NBA 官方本地名单的 38 处差异全部忽略，球队归属和 Player ID 始终以 `nba-current-roster.json` 为准。

## 映射规则

映射版本固定为 `nba2k27-eight-attribute-map.v1`，配置位于 `src/data/nba2k27-rating-map.json`。

| 游戏字段 | NBA 2K27 来源 |
|---|---|
| 投射 | Outside Scoring 分类值；API 新增档案由投篮相关分项确定性推导 |
| 终结 | Inside Scoring 分类值；API 新增档案由篮下、扣篮和背身分项确定性推导 |
| 组织 | Playmaking 分类值；API 新增档案由控球、传球和持球速度分项确定性推导 |
| 外防 | 外线防守、抢断、传球预判、防守稳定性、协防智商加权 |
| 内防 | 内线防守、盖帽、协防智商、防守稳定性、力量加权 |
| 篮板 | Rebounding 分类值 |
| 运动 | Athleticism 分类值 |
| 球商 | 投篮智商、传球智商、协防智商、攻防稳定性、传球预判加权 |

OVR 直接使用来源 OVR；八维属性直接进入比赛引擎。OVR 与八维加权值之间的差额继续通过现有 `overallAdjustment` 保存，因此页面显示不会再次把杰伦·布伦森错误计算为 69。

## 降级规则

API 中不存在完整档案的当前球员保留原有统计模型，并标记 `NBA_2K27_PROFILE_UNAVAILABLE`。这些球员不会被描述成 2K 数据。重新同步只执行统一模块：

```bash
NBA2K_API_KEY="..." npm run data:sync-players
```
